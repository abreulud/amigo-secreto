# Amigo Secreto de Natal

Um site para organizar a troca de presentes de grupos de 3 a 50 pessoas. O organizador define a data, o orçamento e o número de participantes, compartilha o convite e faz o sorteio quando o grupo está completo. Ninguém tira o próprio nome.

## Como participar

1. Abra o link de convite, informe seu e-mail e digite o código que receber.
2. Na aba **Participantes**, cadastre seu nome para entrar no grupo.
3. Em **Minha área**, monte sua lista de presentes. Você pode incluir links e atualizar suas sugestões quando quiser.
4. Depois do sorteio, volte a **Minha área** e toque na etiqueta para descobrir quem você tirou e ver a lista dessa pessoa.

Seu resultado é privado. Além de você, só quem tirou seu nome pode consultar sua lista de presentes.
